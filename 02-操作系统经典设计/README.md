## 特色设计

### 生活类比（每章节都有）

```
进程调度    → 餐厅叫号（谁等最久谁先吃）
内存管理    → 快递柜映射（虚拟柜号→物理柜号）
同步互斥    → 厕所门锁（一次只能一个人进）
文件系统    → 图书馆目录（索引卡→实际书架）
中断/系统调用 → 银行柜台（前台递单，内核办事）
进程间通信  → 邮筒/对讲机/共享阳台
零拷贝      → 工厂流水线（减少搬运环节）
cgroup      → 公寓楼物业（资源配额+视野隔离）
调度器演进  → 十字路口交警的演变
```

### 核心设计原则

1. **分层抽象**：应用不需要知道硬件细节
2. **利用局部性**：缓存最近用的，预取可能要用的
3. **没有银弹**：每次改进都在公平性、吞吐量、延迟之间权衡
4. **权衡是设计**：性能↑往往意味着复杂度↑和维护成本↑
