# 6.6 进程间通信：消息传递

> 两个独立进程怎么交换数据？

---

## 问题

- 无名管道：亲缘进程才能通信
- 信号：只能传递信号码，不能传数据
- 共享内存：最快，但需要同步
- 消息队列：可以传结构化数据

---

## 经典解法

### 共享内存（最快，但需要同步）

```c
// 进程 A：创建共享内存
int shmid = shmget(IPC_KEY, 4096, IPC_CREAT | 0666);
void *shm = shmat(shmid, NULL, 0);
strcpy(shm, "hello from A");

// 进程 B：连接到同一块共享内存
int shmid = shmget(IPC_KEY, 4096, 0666);
void *shm = shmat(shmid, NULL, 0);
printf("%s\n", shm);  // 直接访问，不需要系统调用
```

**注意**：共享内存本身不提供同步，需要额外用 Mutex/Semaphore 保护。

---

### 消息队列（System V / POSIX）

```c
// 发送
msgget(key, IPC_CREAT);
msgsnd(qid, &msg, strlen(msg.text), 0);

// 接收
msgrcv(qid, &msg, sizeof(msg.text), msg_type, 0);
```

**消息队列 vs 管道**：

| | 管道 | 消息队列 |
|---|---|---|
| 生命周期 | 随进程（无名）/ 随内核（有命） | 随内核，直到被显式删除 |
| 方向 | 单向（FIFO） | 双向 |
| 消息边界 | 无（字节流） | 有（每条消息独立） |
| 查找 | 只能从头部读 | 可以按 type 随机读 |

---

## 扩展：Linux 内核 IPC 演进

### System V vs POSIX

```bash
# System V IPC（传统，但仍广泛使用）
ipcs  # 查看当前 IPC 资源

# 消息队列
msgget() msgsnd() msgrcv()
# 信号量
semget() semop() semctl()
# 共享内存
shmget() shmat() shmdt()

# POSIX IPC（更简单，POSIX 语义）
# 消息队列
mq_open() mq_send() mq_receive()
# 信号量
sem_open() sem_wait() sem_post()
# 共享内存
shm_open() mmap() munmap()
```

### mmap 共享内存 vs shmget

```c
// shmget + shmat：System V 共享内存
shmget(IPC_KEY, size, IPC_CREAT);
shmat(shmid, NULL, 0);

// mmap：POSIX 共享内存（文件-backed 或 anonymous）
// 文件-backed（持久化）
int fd = open("/dev/shm/my_shm", O_RDWR);
void *ptr = mmap(NULL, size, PROT_READ|PROT_WRITE, MAP_SHARED, fd, 0);

// anonymous（不落盘，进程间共享）
void *ptr = mmap(NULL, size, PROT_READ|PROT_WRITE,
                 MAP_ANONYMOUS | MAP_SHARED, -1, 0);
```

---

### IPC 性能对比

| 方式 | 延迟 | 适用场景 |
|------|------|---------|
| 管道/Unix Socket | 低（内核缓冲） | 简单数据流 |
| 消息队列 | 中（有内核拷贝） | 结构化消息、异步处理 |
| 共享内存 | 最低（零拷贝） | 高频大数据交换 |
| RPC（gRPC/Thrift） | 高（有序列化） | 跨语言、跨机器 |
