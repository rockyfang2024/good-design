# good-design
好的设计 & 解决方案

> 收录计算机领域经典设计思想、优秀解决方案、设计问题的完整分析。通过这个仓库，建立对计算机设计的**审美直觉**和**设计思考框架**。

---

## 核心理念

计算机科学中的经典问题，往往在几十年前就被最聪明的工程师解决过了。他们的解法不仅有效，而且**优雅**——理解这些解法，能让你在遇到新问题时，站在巨人的肩膀上思考。

本仓库的目标：
- **理解** — 真正搞懂每个设计的来龙去脉
- **审美** — 建立对好设计的直觉判断力
- **迁移** — 把经典设计思想应用到新问题

## 设计审美原则（贯穿全文）

**1. 没有银弹**  
每种方案都有 trade-off。选择某种设计，通常意味着在几个互相冲突的目标之间做取舍。

**2. 利用局部性**  
无论是 CPU 缓存、文件系统预读、还是 CDN，本质上都是利用"最近用过的数据很可能再次被用到"这个事实。

**3. 简单性优先**  
复杂的设计往往脆弱。好的设计会把复杂性藏在接口后面，让使用者在需要时才能看到。

**4. 分层抽象**  
每一层只关注自己的接口，下层为上层服务，但不关心上层的实现细节。互联网协议栈就是最好的例子。

**5. 复用通用解法**  
许多看似不同的问题，底层是同一个经典解法。理解这些共性，能让你举一反三。

## 如何阅读

每篇文档遵循同样的结构：

```
1. 问题 → 描述一个真实的工程挑战
2. 约束 → 列出技术和物理上的限制
3. 经典解法 → 历史上最优雅的解决方案
4. 核心设计思想 → 这个解法背后的原则
5. 延伸思考 → 在现代系统中的变体和应用
```
